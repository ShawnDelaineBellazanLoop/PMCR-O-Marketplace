# CopilotKit frontend redesign

1. Read `SKILL.md` and `references/project-architecture.md`.
2. Inspect the current frontend entry points and existing design tokens.
3. Write a redesign brief to `output/` with goals, page map, states, accessibility rules, and acceptance criteria.
4. Route planning through `planner`, implementation through `maker`, checks through `checker`, and durable lessons through `reflector`.
5. Edit only the necessary files under `src/frontend` using focused changes.
6. Verify the CopilotKit route and AG-UI server boundary remain intact.
7. Run available TypeScript/build checks and browser checks when available.
8. Return the brief, changed-file links, validation results, and unresolved decisions.

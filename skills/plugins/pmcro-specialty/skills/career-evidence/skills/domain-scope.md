# Career Evidence Domain Skill

Documentation-only specialty scope for the PMCR-O Colony. Consulted by pmcro-loop when a cycle's true_intent falls under it. Never reimplements the PMCR-O loop itself.

## Owns
- Career evidence collection and timeline
- Achievement documentation
- Evidence-based career narrative

## Does Not Own
- Strategic direction (`ceo`)
- Budgeting/cash flow (`cfo`)
- Technical architecture (`cto`)
- Day-to-day workflow execution (`coo`)

## Domain Consulting Pattern

Each domain is documentation-only scope. When a cycle's `true_intent` falls under career evidence, pmcro-loop consults this skill. It **decides and routes** — it never performs the specialist work itself.

## Commands
- `timeline` — build or update a career evidence timeline

## Guardrails
1. Every evidence item names the achievement, the impact, and the proof.
2. Approve evidence scope; delegate execution. Do not do the specialist work.
3. "No action needed" is a valid decision — not every input requires intervention.

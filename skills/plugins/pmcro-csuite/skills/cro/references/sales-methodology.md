# Sales Methodology Reference — CRO Domain

Pipeline management and deal qualification frameworks.

## Pipeline Stages

Every deal moves through these stages:

| Stage | Definition | Exit Criteria |
|---|---|---|
| Lead | Unqualified contact | Qualification call completed |
| Qualified | Need + budget + authority confirmed | Discovery call scheduled |
| Proposal | Solution presented | Proposal sent |
| Negotiation | Terms in discussion | Contract out for signature |
| Closed Won | Signed and invoiced | Revenue recognized |
| Closed Lost | Deal lost | Loss reason documented |

## Deal Health Scoring

Each deal gets a health score (0-100):

```
Health = Stage_Progress(40%) + Activity_Recency(30%) + Next_Step_Clarity(30%)

Stage_Progress:    % through pipeline (0-40)
Activity_Recency:  30 if contacted <7 days, 15 if <14 days, 5 if <30 days, 0 if >30
Next_Step_Clarity: 30 if next action is specific + dated, 15 if vague, 0 if none
```

**Thresholds:**
- 80-100: Healthy — on track
- 60-79: Watch — needs attention this week
- 40-59: At Risk — intervention required
- <40: Critical — likely lost without immediate action

## Win/Loss Analysis

Every lost deal answers:

1. **Primary reason**: price, product fit, competitor, timing, relationship, process
2. **Controllable factor**: what could we have done differently?
3. **Pattern check**: is this the 3rd+ loss for the same reason? → escalate to CEO/CPO

## Proposal Structure

Every proposal includes:

1. **Problem statement** — the client's situation in their words
2. **Solution** — what we propose and why it fits
3. **Timeline** — key milestones and delivery dates
4. **Investment** — pricing, payment terms, what's included/not
5. **Next step** — specific call to action with a date

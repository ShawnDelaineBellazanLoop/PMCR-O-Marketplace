The core PMCR-O framework — Plan, Make, Check, Reflect, Orchestrate. Embodies Behavioral Intent Programming.

| Law | Constraint |
|---|---|
| EC-001 | Discovery verbs are always economically justified |
| EC-002 | TYPE 2 tools never enter dispatch_decisions |

## Framework Laws

- **PMCRO-LAW-001** — Federation Board runs on every seed before any response
- **PMCRO-LAW-002** — Never reduce this to "just prompting"
- **PMCRO-LAW-003** — O-Mode classified before any loop structure is recommended
- **PMCRO-LAW-004** — Constraints always written in first-person, specific, observable form
- **PMCRO-LAW-005** — Trail commercialisation context never skipped when discussing agent expertise

## Frame Chain

```
Intent Envelope → [Planner] → PlanFrame
PlanFrame       → [Maker]   → MakerFrame
MakerFrame      → [Checker] → CheckerFrame
CheckerFrame    → [Reflector] → ReflectorFrame → next Intent Envelope
```

## Guardrails

1. The Orchestrator owns intent, not the skills.
2. Skills are siblings, not a hierarchy.
3. Frames are immutable once sealed.
